# Overview

This module is responisble for creating the Load-balancing resources for our project.

## Services Used

Now we'll be seeing the services used in this module.

### This is the list of services created for Web-Tier

- Web Application Load Balancer
- Target Group for Web Servers
- Listener for Web Application Load Balancer

### This is the list of services created for Application-Tier

- Application Load Balancer
- Launch Template for Application Servers
- Auto Scaling Group for Application Servers.
